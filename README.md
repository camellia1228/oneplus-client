# OnePlus

화면 중앙으로 날아오는 노트를 방향에 맞춰 치는 리듬게임입니다. 상하좌우 네 방향에서 노트가 날아오고, 노트가 중앙에 닿는 순간에 맞춰 같은 방향 키를 누르면 됩니다.

## 1. 시작하기

1. 메인 화면에서 오른쪽 위 user 영역의 마우스포인트를 호버링하면 팝업되는 창 안에 `Login to Google` 버튼으로 로그인합니다.
2. 이름이 표시되면 로그인된 것입니다. 로그아웃은 `LogOut` 버튼을 누르세요.
3. 가운데 Start 버튼을 누르면 곡 선택 화면으로 이동합니다.

## 2. 곡 고르기

- 오른쪽 목록에서 곡을 클릭하면 왼쪽에 제목, 아티스트, 이미지가 나오고 미리듣기가 재생됩니다.
- 마음에 드는 곡을 고른 뒤 Play 버튼을 누르면 게임이 시작됩니다.

## 3. 조작법

| 방향 | 키 |
|---|---|
| 위 | `W` 또는 `↑` |
| 왼쪽 | `A` 또는 `←` |
| 아래 | `S` 또는 `↓` |
| 오른쪽 | `D` 또는 `→` |

- 한글 입력 상태나 맥에서도 그대로 동작합니다.
- 노트는 화면 가장자리에서 중앙으로 이동합니다. 위에서 오는 노트는 `W`, 왼쪽에서 오는 노트는 `A`처럼 노트가 오는 방향의 키를 누르세요.
- 키를 누르는 동안 해당 방향의 버튼 이미지가 바뀝니다.

## 4. 판정

노트가 중앙에 닿는 순간에 얼마나 가깝게 눌렀는지에 따라 판정이 나뉩니다.

| 판정 | 허용 오차 | 정확도 반영 |
|---|---|---|
| Perfect | ±40ms | 100% |
| Great | ±80ms | 80% |
| Good | ±120ms | 50% |
| Bad | ±160ms | 20% |
| Miss | 그 이상, 또는 누르지 않음 | 0% |

- **콤보**: Perfect, Great, Good이면 콤보가 쌓이고, Bad나 Miss가 나오면 끊깁니다. 오른쪽 아래에 표시됩니다.
- **정확도**: 왼쪽 아래에 현재 정확도가 표시됩니다. 모든 판정의 평균입니다.

## 5. 결과와 랭크

곡이 끝나면 잠시 뒤 결과 화면이 나옵니다. 정확도에 따라 랭크가 정해집니다.

| 랭크 | 정확도 |
|---|---|
| X | 100% |
| S | 95% 이상 |
| A | 90% 이상 |
| B | 70% 이상 |
| C | 70% 미만 |

`Esc`를 누르면 곡 선택 화면으로 돌아갑니다.

## 6. 설정 (판정이 어긋날 때)

메인 화면에서 **Setting** 버튼을 누르면 왼쪽에 설정 창이 열립니다. `OFFSET (ms)` 값을 바꾸면 판정 타이밍을 보정할 수 있습니다.

- 늦게 눌러야 Perfect가 뜬다면 **양수**를 입력하세요. 예: `50`
- 일찍 눌러야 Perfect가 뜬다면 **음수**를 입력하세요. 예: `-30`
- 블루투스 이어폰처럼 소리가 늦게 들리는 환경에서 특히 도움이 됩니다.
- 값은 브라우저에 저장되고, 다음 게임부터 적용됩니다.

## 7. 내 곡 올리기

메인 화면의 **Edit** 버튼을 누르면 업로드 화면으로 이동합니다.

1. 제목(TITLE)과 아티스트(ARTIST)를 입력합니다.
2. 음원(AUDIO)과 이미지(IMAGE) 파일을 선택합니다. 모두 필수입니다.
3. `Upload`를 누르면 서버에 올라가고, 곡 선택 화면에 표시됩니다.

## 문제가 생겼을 때

- 곡 목록이 비어 있어요: 서버에 연결되지 않았거나 등록된 곡이 없는 경우입니다. 서버가 켜져 있는지 확인하세요.
